# Changelog

Все заметные изменения проекта — здесь, по датам, новые сверху. Формат
свободный (без строгого SemVer — деплой непрерывный, не по релизам), но
каждая запись — одна строка на PR: что изменилось и зачем, номер PR и
короткий hash merge-коммита (`git log --oneline -1 <PR>` после мерджа) —
тот же, что появляется в футере UI / `docker inspect ... image.revision`
после деплоя этого коммита.

## 2026-08-02

- Синхронизирован `Caddyfile` с тем, что реально работает на проде после
  инцидента ниже: сайт адресован `:80` (не доменным именем — настоящая
  причина, почему редиректов больше не будет), `basicauth` включён по
  умолчанию (больше не нужно вручную редактировать файл на каждом
  деплое), `reverse_proxy` через `CADDY_UPSTREAM`. Заодно убрана
  переменная `DOMAIN` — была мёртвой конфигурацией и вводила в
  заблуждение, что этот Caddy сам держит TLS/домен (не так — этим
  занимается edge-прокси выше по цепочке). (#23, `d65c90c`)
- Прод-инцидент: `hvac.way-to-self.com` зациклился на
  `ERR_TOO_MANY_REDIRECTS` — внутренний Caddy за WireGuard-туннелем
  форсировал HTTPS для доменного site-адреса и редиректил уже
  расшифрованный HTTP обратно на https, что возвращалось через внешний
  Caddy как HTTP снова, по кругу. Фикс — `auto_https off`. (#22, `7b0fe74`)
- Добавлены `ROADMAP.md` (публичные направления развития) и `DEPLOY.md`
  (деплой по фазам/обновление/откат с объяснениями) — оба были упомянуты
  в документации как существующие, но никогда не создавались. ROADMAP.md
  сознательно ограничен пользовательскими фичами, без implementation-
  деталей и бизнес-стратегии. (#20, `1c3e8dd`)
- Добавлен `CHANGELOG.md` (этот файл) — по одной строке на PR, с hash
  merge-коммита, вместо того чтобы держать хронологию только в git
  log/PR-истории. (#18, `1f8551c`)
- `CLAUDE.md` (приватный контекст для Claude Code — инфра, роадмап, планы)
  добавлен в `.gitignore`; никогда не коммитился, чистить историю не
  потребовалось. (#17, `954105a`)
- Добавлена шпаргалка `commands.md` — команды для прода (деплой, старт/стоп,
  логи, basic auth, откат) без сопутствующих объяснений. (#16, `e918a79`)
- Исправлен бесконечный цикл запроса пароля в Caddy basic auth: docker
  compose обрубал `$` в bcrypt-хэше при подстановке `${VAR}` из `.env` —
  хэш никогда не совпадал ни с одним паролем. (#15, `d702cf7`)

## 2026-08-01

- Добавлен `Cache-Control: no-cache` на статику — браузер мог тихо
  показывать закэшированную версию после деплоя, маскируя уже
  задеплоенный фикс. (#14, `b79bbcc`)
- Исправлен расчёт SH/SC: перегрев/переохлаждение (дельта температур)
  считались по формуле для абсолютной температуры (1°F дельта показывало
  как -17°C вместо ~0.6°C) — теперь отдельная `Δ°F`/`Δ°C` конверсия.
  Заодно — расплывчатые breadcrumb-лейблы вида "Above normal" стали
  контекстными ("Suction pressure: above normal" и т.п.). (#13, `761ab73`)
- Добавлен git-хук `post-merge` — `git pull` триггерит именно его, а не
  `post-checkout`/`post-commit`, из-за чего версия в футере/label не
  обновлялась на деплой-машинах после обычного pull. (#12, `b94c6b3`)
- Добавлена видимая версия сборки: git commit hash в Docker OCI-label
  (`org.opencontainers.image.revision`) + мелкая строка в футере UI,
  автоматически из `GIT_COMMIT`/`GIT_COMMIT_DATE` при билде. (#11, `e024e0d`)
- Исправлены обрывающиеся на середине предложения ответы AI-ассистента:
  `max_tokens` был слишком мал (700→2048, настраивается), плюс явный
  alert на фронте, если Anthropic реально обрезал ответ (`stop_reason`). (#10, `8f7d8dc`)
- Добавлен P-T калькулятор перегрева/переохлаждения: 15 хладагентов с
  реальными табличными данными (не формула), линейная интерполяция,
  явный отказ от расчёта (вместо экстраполяции) при давлении вне
  табличного диапазона хладагента — с настойчивым critical-alert. (#9, `2bc54f1`)
- Исправлено: длинный неразрывный текст в ответе AI ломал вёрстку на
  мобильных (растягивал страницу по горизонтали, а не просто требовал
  скролла). (#8, `5bc504c`)
- Добавлен шаг выбора производителя/модели оборудования после типа
  оборудования, со ссылкой на официальную документацию в конце сессии. (#7, `45f8ab0`)
- Добавлен тип узла `measurement` — структурированный сбор измерений
  (ток компрессора/вентилятора vs RLA/FLA×SF) с ненавязчивым alert при
  превышении заводского референса. (#6, `617a847`)
- Безопасный рендеринг markdown в ответах AI (`**bold**` больше не
  показывается как есть) + новая ветка диагностики hot gas bypass
  hunting. (#5, `4da8951`)
- Добавлен тип узла `numeric_input` — точный числовой ввод с
  маршрутизацией по диапазонам значений вместо качественных вопросов
  "выше/ниже нормы". (#4, `09333d8`)
- Добавлен юридический disclaimer — постоянный баннер в UI + обязательная
  заключительная строка в каждом ответе AI. (#3, `3d8f902`)
- Пройденные чек-листы сохраняются в SQLite для последующего анализа
  частых паттернов неисправностей. (#2, `52b89c7`)
- Добавлена RU/EN локализация с автоматическим дублированием единиц
  измерения (psig/kPa, °F/°C, microns/inHg/mmHg). (#1, `d48e2c8`)
