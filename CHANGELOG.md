# Changelog

Все заметные изменения проекта — здесь, по датам, новые сверху. Формат
свободный (без строгого SemVer — деплой непрерывный, не по релизам), но
каждая запись — одна строка на PR: что изменилось и зачем, номер PR и
короткий hash merge-коммита (`git log --oneline -1 <PR>` после мерджа) —
тот же, что появляется в футере UI / `docker inspect ... image.revision`
после деплоя этого коммита.

## 2026-08-03

- Иконка favicon добавлена и в шапку приложения вместо эмодзи 🔧. (#48, `a434ca9`)

- Добавлен favicon (гаечные ключи крест-накрест на баллоне хладагента). (#46, `ade4d8d`)

- На экране сравнения давления с P-T таблицей (`nc_fans_ok`) теперь
  спрашивается и suction, и head pressure (два блока по 3 кнопки) — раньше
  head вообще не спрашивался, и случай "suction в норме, а head нет"
  терялся в общем freeform AI-промпте. "Log exact"/"Calculate SH/SC
  precisely" убраны из общего списка и перенесены в Deeper diagnosis
  (Phase 4) как отдельный пункт рядом с metering device — переиспользует
  обычную навигацию графа, не изолированный component-check остров, т.к.
  сама цепочка расчёта уже самодостаточна. (#44, `5a89c17`)
- Чекбоксы intake-чеклиста ("TXV present?" и т.п.) заменены на настоящий
  Yes/No/Not sure — раньше "Нет" нельзя было явно записать, только N/A
  (не то же самое, что "нет"). Добавлена взаимоисключаемость для типа
  metering device (TXV/капиллярная трубка/другое — реально может быть
  только один), пропуск избыточных вопросов в component-check, если тип
  уже известен из Phase 1, и фикс единиц измерения в узких полях ввода
  (плюс откат регрессии, которую сам же внёс — сужение задело
  manufacturer/model/refrigerant поля). (#40, `72a884a`)
- Standing pressure test для non-condensables теперь считается
  автоматически по P-T таблице (хладагент + температура + давление →
  сравнение с ожидаемым давлением насыщения), а не через ручной чекбокс
  "сверился сам". (#41, `edee303`)
- Уточнён заголовок и добавлен чип хладагента на качественном вопросе
  сравнения давления с P-T таблицей (`nc_fans_ok`). (#42, `44d7640`)

## 2026-08-02

- Найден и исправлен баг: `AI_ASSIST_MAX_TOKENS`/`AI_DEEP_DIVE_MAX_TOKENS`
  читались в `main.py`, но ни `docker-compose.yml`, ни
  `docker-compose.prod.yml` не прокидывали их в контейнер — значение в
  `.env` реально не влияло ни на что, тихо откатываясь к дефолтам кода.
  Прокинуто в оба compose-файла; рекомендуемые значения в `.env.example`
  подняты (2048→4096, 3000→6000 — deep-dive остаётся выше обычного
  лимита). **Требуется вручную добавить обе строки в реальные `.env` на
  dev и на проде** — `.env.example` не переприменяется поверх
  существующего `.env`. (#38, `4d94d91`)
- Пилот component sub-tree для metering device внутри Phase 4 intake-чеклиста
  (установлен? → тип: капиллярная трубка/fixed orifice/ТРВ/EEV → состояние →
  если неисправен — реалистичный список failure modes под тип + свободное
  описание), переиспользует движок question/result узлов графа, находка
  возвращается в intake-item, а не продолжает основной граф. "Масляные
  потёки в нетипичных местах" добавлены как failure-mode во все 4 типа,
  тем же уточнена формулировка на `leak_refrig`/`leak_start`. Отдельно:
  `AI_DEEP_DIVE_MAX_TOKENS` — увеличенный лимит токенов для AI-запроса
  после прохождения intake-чеклиста. (#36, `5c1c1ff`)
- Чекбоксы в intake-чеклисте заменены на крупные кнопки-переключатели
  (✓ Сделано / N/A, ~52px, под перчатки) — старый UI с мелкими чекбоксами
  вводил в заблуждение. Новый тип пункта `select` (N кнопок + N/A, рамка
  зелёная/красная/серая по совпадению с "нормой") — `moisture_reading`
  мигрирован на него с `field`. (#34, `a64fd87`)
- В футер добавлен ник автора "IvanK". (#33, `04c7d31`)
- В футере рядом с commit hash/датой деплоя добавлен `session: <8 символов
  session_id>` — тот же id, что уже хранится в localStorage для
  персистентности чек-листа. Цель — скриншот фидбека от техника сразу несёт
  ID, по которому можно достать node_path/checklist_state из БД без
  переписки "что ты нажимал". (#31, `148ee9b`)
- Чек-лист после диагностики (10 result-узлов) + персистентность сессии
  (продолжить/начать заново после перезагрузки страницы, финальный экран),
  фазовый intake-чеклист (визуальный осмотр → электрика → controls/safety →
  холодильный контур, opt-in по кнопке "Углублённая диагностика", не
  обязательный) и два универсальных гейт-вопроса перед выбором симптома
  ("питание подано?", "термостат подаёт команду?"). Чек-лист/intake-данные
  теперь попадают в контекст AI-ассистента (раньше не попадали — баг).
  (#29, `4ee7ad5`)
- Общий disclaimer об ответственности в README (отдельно от AI-safety
  баннера) + обновлена устаревшая секция "Архитектура". (#28, `70e818a`)
- Добавлен `tools/visualize_graph.py` — рендер graph.json в Mermaid-схему,
  инструмент разработчика, не часть Docker-образа. (#27, `f8af3ed`)
- Языковая политика документации: `README.md` теперь bilingual — английская
  версия стала основной, русская вынесена в `README.ru.md` (перекрёстные
  ссылки сверху обоих файлов). `ROADMAP.md`, `DEPLOY.md`, `commands.md`,
  `Caddyfile`, `.env.example` переведены на английский — стандартный дефолт
  для repo-facing документов. `CHANGELOG.md` (этот файл) сознательно
  остаётся только на русском — единственный реальный читатель — автор.
  UI/граф вопросов не затронуты, они были bilingual с самого начала. (#25, `6ccf830`)
- Синхронизирован `Caddyfile` с тем, что реально работает на проде после
  инцидента ниже: сайт адресован `:80` (не доменным именем — настоящая
  причина, почему редиректов больше не будет), `basicauth` включён по

- Добавлен `CHANGELOG.md` (этот файл) — по одной строке на PR, с hash

## 2026-08-01

- Добавлен `Cache-Control: no-cache` на статику — браузер мог тихо
  показывать закэшированную версию после деплоя, маскируя уже
  задеплоенный фикс. (#14, `b79bbcc`)
- Исправлен расчёт SH/SC: перегрев/переохлаждение (дельта температур)
  считались по формуле для абсолютной температуры (1°F дельта показывало
  как -17°C вместо ~0.6°C) — теперь отдельная `Δ°F`/`Δ°C` конверсия.
  Заодно — расплывчатые breadcrumb-лейблы вида "Above normal" стали
  контекстными ("Suction pressure: above normal" и т.п.). (#13, `761ab73`)
- Добавлен git-хук `post-merge` — `git pull` триггерит именно его, а не
  `post-checkout`/`post-commit`, из-за чего версия в футере/label не
  обновлялась на деплой-машинах после обычного pull. (#12, `b94c6b3`)
- Добавлена видимая версия сборки: git commit hash в Docker OCI-label
  (`org.opencontainers.image.revision`) + мелкая строка в футере UI,
  автоматически из `GIT_COMMIT`/`GIT_COMMIT_DATE` при билде. (#11, `e024e0d`)
- Исправлены обрывающиеся на середине предложения ответы AI-ассистента:
  `max_tokens` был слишком мал (700→2048, настраивается), плюс явный
  alert на фронте, если Anthropic реально обрезал ответ (`stop_reason`). (#10, `8f7d8dc`)
- Добавлен P-T калькулятор перегрева/переохлаждения: 15 хладагентов с
  реальными табличными данными (не формула), линейная интерполяция,
  явный отказ от расчёта (вместо экстраполяции) при давлении вне
  табличного диапазона хладагента — с настойчивым critical-alert. (#9, `2bc54f1`)
- Исправлено: длинный неразрывный текст в ответе AI ломал вёрстку на
  мобильных (растягивал страницу по горизонтали, а не просто требовал
  скролла). (#8, `5bc504c`)
- Добавлен шаг выбора производителя/модели оборудования после типа
  оборудования, со ссылкой на официальную документацию в конце сессии. (#7, `45f8ab0`)
- Добавлен тип узла `measurement` — структурированный сбор измерений
  (ток компрессора/вентилятора vs RLA/FLA×SF) с ненавязчивым alert при
  превышении заводского референса. (#6, `617a847`)
- Безопасный рендеринг markdown в ответах AI (`**bold**` больше не
  показывается как есть) + новая ветка диагностики hot gas bypass
  hunting. (#5, `4da8951`)
- Добавлен тип узла `numeric_input` — точный числовой ввод с
  маршрутизацией по диапазонам значений вместо качественных вопросов
  "выше/ниже нормы". (#4, `09333d8`)
- Добавлен юридический disclaimer — постоянный баннер в UI + обязательная
  заключительная строка в каждом ответе AI. (#3, `3d8f902`)
- Пройденные чек-листы сохраняются в SQLite для последующего анализа
  частых паттернов неисправностей. (#2, `52b89c7`)
- Добавлена RU/EN локализация с автоматическим дублированием единиц
  измерения (psig/kPa, °F/°C, microns/inHg/mmHg). (#1, `d48e2c8`)
