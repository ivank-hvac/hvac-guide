Model number lookup

Pilot feature — look up a unit's specs by model number. First lookup for a model uses AI + web search and gets saved; every lookup after that for the same model is instant.

Not a database of real equipment — an estimate from published specs. Always verify against the actual nameplate before relying on it.

Поиск по номеру модели

Пилотная функция — поиск спеков оборудования по номеру модели. Первый поиск конкретной модели идёт через AI + веб-поиск и сохраняется; каждый следующий поиск той же модели — мгновенный.

Это не база реального оборудования, а оценка по опубликованным данным. Всегда сверяйтесь с настоящим шильдиком, прежде чем полагаться на эти цифры.
